# Lugwise

A guided drum tuner for snare and toms that runs in the browser. It listens through your mic and walks you through loosening the heads, the star pattern, setting the drum's note, evening out every lug, and the bottom head. The drum on screen is a live 3D model (Three.js): drag it to spin, watch the key show each turn, and see the drum flip for the bottom head.

Live: https://twominutesawayconsultancy-commits.github.io/lugwise/

`index.html` is the built single-file app. Source is in `source/`: `cd source && npm i && python3 build.py` writes `dist/index.html`.
